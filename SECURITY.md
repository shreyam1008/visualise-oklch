# Security policy

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** flow. Include the extension version, VS Code version, reproduction steps, and impact, without private workspace contents.

The latest released version receives security fixes. Ordinary rendering defects and feature requests belong in the public issue tracker.

Visualise OKLCH processes editor text inside VS Code and does not require a hosted service. A report involving unexpected network access, command execution, workspace trust, or unsafe parsing should be treated as security-sensitive.
